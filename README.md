# 安装方法：
解压，然后把CarDataRecorder文件夹丢到游戏根目录\apps\lua里（如：D:\steam\steamapps\common\assettocorsa\apps\lua）  
# 使用方法：
游戏内可使用该app录制车辆遥测数据为AIM-csv格式的csv文件，可导入华*自研赛车数据分析软件https://github.com/Shen-18/SCUT-Racing-Telemetry  
# 你需要知道的
该插件基于csp提供的api开发，如果你没有装csp那显然是用不了的
默认录制文件保存位置位于C:\Users\用户名\Documents\Assetto Corsa
现版本时间采样有bug 暂时懒得修了
